
# MATPLOTLIB — Data Visualization Library

## What is Matplotlib?

Matplotlib is a Python library for creating charts, graphs, and plots. It turns your data (numbers) into visual pictures so you can see patterns, trends, and comparisons easily.

Think of it like: Excel charts, but in Python code.

---

## How Does Matplotlib Plot Data?

### The Basic Process:

1. **You give it data** (X values and Y values)
2. **Matplotlib draws points** on a coordinate system
3. **Connects the points** (for line charts) or draws shapes (bars, etc.)
4. **Shows it in a window** or saves as an image

### Simple Example:

```python
import matplotlib.pyplot as plt

# Data
days = [1, 2, 3, 4, 5]
prices = [100, 105, 103, 108, 110]

# Plot
plt.plot(days, prices)  # Draw line connecting these points
plt.show()              # Display the chart
```

**What happens:**
- `plt.plot(x, y)` — tells matplotlib: "draw a line from point (1,100) to (2,105) to (3,103)..."
- `plt.show()` — opens a window and displays the chart

---

## How Does It Open a Window Automatically?

### Behind the Scenes:

When you call `plt.show()`:

1. Matplotlib uses your computer's **GUI framework** (Tkinter on Mac/Linux, Windows GUI on Windows)
2. Creates a new window using the operating system
3. Renders the chart as an image inside that window
4. Adds interactive controls (zoom, pan, save button)

**You don't need to code any of this** — `plt.show()` does it all automatically.

### Interactive Window Features:

- **Zoom:** Click and drag
- **Pan:** Move the chart around
- **Save:** Button to export as PNG
- **Home:** Reset zoom
- **Close:** Exit the window

## What Can Matplotlib Do?

### 1. Line Charts (most common for stocks)

Track changes over time — perfect for stock prices.

```python
plt.plot(dates, prices)
plt.show()
```

**Use for:** Stock prices, temperature over time, sales trends

---

### 2. Multiple Lines (compare stocks)

Show multiple stocks on one chart with different colors.

```python
plt.plot(dates, reliance_prices, label="RELIANCE", color="blue")
plt.plot(dates, tcs_prices, label="TCS", color="green")
plt.legend()  # Show which line is which
plt.show()
```

**Use for:** Comparing performance of multiple stocks

---

### 3. Bar Charts

Compare values side by side.

```python
stocks = ["RELIANCE", "TCS", "ICICI"]
returns = [5.2, 8.1, 3.4]

plt.bar(stocks, returns)
plt.show()
```

**Use for:** Monthly returns comparison, volumes, sector performance

---

### 4. Scatter Plots

Show individual data points (no connecting line).

```python
plt.scatter(risk, return)  # Each stock is one dot
plt.show()
```

**Use for:** Risk vs return analysis, finding outliers

---

### 5. Histograms

Show distribution — how often values appear.

```python
plt.hist(daily_returns, bins=20)
plt.show()
```

**Use for:** Understanding volatility patterns, return distribution

---

### 6. Subplots (multiple charts in one window)

Show different views side by side.

```python
plt.subplot(2, 1, 1)  # 2 rows, 1 column, chart #1
plt.plot(dates, prices)

plt.subplot(2, 1, 2)  # Chart #2 below chart #1
plt.plot(dates, volumes)

plt.show()
```

**Use for:** Price chart on top, volume chart below

---

### 7. Styling & Customization

Make charts look professional.

```python
plt.plot(dates, prices, color="red", linewidth=2, linestyle="--")
plt.title("RELIANCE Stock Price")
plt.xlabel("Date")
plt.ylabel("Price (₹)")
plt.grid(True)  # Add grid lines
plt.show()
```

**Options:**
- Colors: "red", "blue", "green", "#FF5733" (hex codes)
- Line styles: "-" (solid), "--" (dashed), "-." (dash-dot), ":" (dotted)
- Markers: "o" (circle), "s" (square), "^" (triangle)

---

### 8. Save Charts as Images

Export for Twitter, reports, presentations.

```python
plt.plot(dates, prices)
plt.savefig("stock_chart.png", dpi=300, bbox_inches="tight")
```

**Parameters:**
- `dpi=300` — high quality (higher = sharper)
- `bbox_inches="tight"` — no extra white space
- Formats: `.png`, `.jpg`, `.pdf`, `.svg`

## How Matplotlib Works Internally

### The Two Main Components:

**1. Figure** — The entire window/canvas (the container)
**2. Axes** — The actual chart area (where data is plotted)

```
┌─────────────────────────────────┐
│ Figure (window)                 │
│  ┌───────────────────────────┐  │
│  │ Axes (chart area)         │  │
│  │   • Data points           │  │
│  │   • Lines                 │  │
│  │   • Labels                │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘
```

**Simple way (what you've been using):**
```python
plt.plot(x, y)  # Matplotlib creates figure + axes automatically
plt.show()
```

**Advanced way (explicit control):**
```python
fig, ax = plt.subplots()  # Create figure and axes manually
ax.plot(x, y)
plt.show()
```

## Common Patterns in Finance

### Pattern 1: Single Stock Price Chart

```python
import yfinance as yf
import matplotlib.pyplot as plt

data = yf.Ticker("RELIANCE.NS").history(period="1mo")
plt.plot(data.index, data["Close"], color="blue", linewidth=2)
plt.title("RELIANCE Stock Price (1 Month)")
plt.xlabel("Date")
plt.ylabel("Price (₹)")
plt.grid(True, alpha=0.3)  # Faint grid
plt.show()
```

---

### Pattern 2: Compare Multiple Stocks

```python
stocks = ["RELIANCE.NS", "TCS.NS", "ICICI.NS"]
colors = ["blue", "green", "red"]

for stock, color in zip(stocks, colors):
    data = yf.Ticker(stock).history(period="1mo")
    plt.plot(data.index, data["Close"], label=stock.split(".")[0], color=color)

plt.title("Stock Price Comparison")
plt.xlabel("Date")
plt.ylabel("Price (₹)")
plt.legend()
plt.grid(True)
plt.show()
```

---

### Pattern 3: Price + Volume (Subplots)

```python
data = yf.Ticker("RELIANCE.NS").history(period="1mo")

# Top chart: Price
plt.subplot(2, 1, 1)
plt.plot(data.index, data["Close"], color="blue")
plt.title("RELIANCE — Price & Volume")
plt.ylabel("Price (₹)")
plt.grid(True)

# Bottom chart: Volume
plt.subplot(2, 1, 2)
plt.bar(data.index, data["Volume"], color="gray", alpha=0.5)
plt.ylabel("Volume")
plt.xlabel("Date")
plt.grid(True)

plt.tight_layout()  # Prevent overlapping
plt.show()
```

## Why Use Matplotlib for Finance?

✅ **See trends instantly** — spot uptrends, downtrends, patterns
✅ **Compare stocks visually** — which one performed best?
✅ **Communicate results** — charts are easier to understand than numbers
✅ **Export for reports** — save as PNG for presentations/social media
✅ **Interactive exploration** — zoom into specific date ranges

## Key Takeaways

1. **Matplotlib = turn data into pictures**
2. **`plt.plot(x, y)`** — most common function (line chart)
3. **`plt.show()`** — display the chart in a window
4. **`plt.savefig()`** — export as image
5. **Colors, labels, legends** — make charts readable

## Common Workflow

```python
# 1. Import
import matplotlib.pyplot as plt

# 2. Get data
# (from yfinance, pandas, etc.)

# 3. Plot
plt.plot(x, y)

# 4. Style (optional)
plt.title("My Chart")
plt.xlabel("X axis")
plt.ylabel("Y axis")
plt.legend()
plt.grid(True)

# 5. Show or save
plt.show()           # Display
# OR
plt.savefig("chart.png")  # Save
```
